# NCSU Projects
Overview of key projects I’ve worked on during my Computer Science coursework, primarily focusing on software tools, data structures, and algorithm design. All projects are private in compliance with NCSU policies, but I'm happy to share specific repositories upon request.

---

## Key Projects

### 1. AES Encrypter & Decrypter
- **Language**: C  
- **Skills**: AES encryption & decryption, file handling, binary file manipulation, CLI, software testing  
- **Highlights**: Implements the 128-bit AES algorithm for encrypting and decrypting text and binary files. Includes padding to handle non-16-byte blocks.  
- **Testing**: Validated with course-provided `test.sh` script covering a range of test cases.  
- **Future Improvements**: GUI development, advanced key management techniques.

---

### 2. Generic Queue Implementation
- **Language**: C  
- **Skills**: Data structures, generic programming, memory management, CLI  
- **Highlights**: Implements a generic queue using a linked list that supports various data types like integers, real numbers, and strings.  
- **Testing**: Tested with a `test.sh` script ensuring robustness and correctness.  
- **Future Improvements**: Additional queue operations, enhanced error handling, performance optimization.

---

### 3. College Scheduler
- **Language**: C  
- **Skills**: File I/O, data structures, string manipulation, dynamic analysis tools  
- **Highlights**: Allows users to view a course catalog, manage their schedule, and sort courses by various criteria.  
- **Testing**: Thoroughly tested using the provided `test.sh` script.  
- **Future Improvements**: Adding prerequisites and credit limits for courses, improving error handling.

---

### 4. Identifier Search Utility
- **Language**: C  
- **Skills**: Text processing, regular expressions, error handling, CLI  
- **Highlights**: Searches for identifiers in source files, prints lines containing identifiers, and highlights occurrences. Supports options for line numbers and surrounding context.  
- **Testing**: Comprehensive tests using `test.sh` to ensure accurate and reliable identifier detection.  
- **Future Improvements**: Performance optimization, multi-file search, GUI development.

---

### 5. Base 10 and Base 12 Calculator
- **Language**: C  
- **Skills**: Arithmetic operations, low-level programming, control structures  
- **Highlights**: Supports arithmetic operations in both base 10 and base 12, with proper operator precedence and overflow detection.  
- **Testing**: Validated with `test.sh` covering a range of test cases for both bases.  
- **Future Improvements**: Expanding support to other bases, enhancing input validation.

---

### 6. TrailManager
- **Language**: Java  
- **Skills**: Algorithm design, runtime analysis, system testing  
- **Highlights**: Calculates distances between landmarks in a park and determines optimal first aid locations using a Skip List Map data structure.  
- **Testing**: Validated using JUnit test cases and runtime performance experiments.  
- **Future Improvements**: Implementing a non-recursive algorithm for improved performance.

---

### 7. WolfScheduler
- **Language**: Java  
- **Skills**: Unit testing, version control, continuous integration  
- **Highlights**: A course and event planner allowing users to manage their schedules with options to save, load, and modify schedules.  
- **Testing**: Extensively tested using JUnit test cases for all major components.  
- **Future Improvements**: Improving the GUI and ensuring robust boundary verification.
